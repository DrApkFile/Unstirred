# The demo video: the static replay site, and the render

What this file settles: that `site/` is written from the gate's own page module, and that
`video/out/unstirred-demo.mp4` was produced by a recorded run of HyperFrames rather than described.
It says nothing about the Zcash network — the chain claims in the film are the recorded runs it
re-enacts, each one named on screen and each one already in this ledger.

## The static replay site

```
./scripts/export-replay-site.sh                      # writes site/
./scripts/export-replay-site.sh video/assets/site    # the same pages, for the video's browser scenes
```

Each run wrote **11 pages**: the five recorded acts (`act1-rule`, `act2-admitted`, `act3-refused`,
`act4-newcomer`, `act5-second-room`), each as `<act>.html` and `<act>.present.html`, plus
`index.html`, the room picker. They come out of `crates/unstirred-gate/examples/export-replay-site.rs`,
which calls the gate's own `page::room_document` and `page::picker_document`, so an exported file is
the document the gate serves at `/room/<context>?replay=<act>` and not a second rendering of the
same design. A replay page polls nothing and its own Content-Security-Policy is `connect-src 'none'`,
so `site/` opens with no gate, no chain, no wallet and no nf-server.

Known limitation, printed by the script itself: the picker's room cards link to `/room/<context>`,
which is a gate route and not a file in `site/`. Publishing the site means deciding what those
links should point at. **GitHub Pages is not set up**, by instruction.

## The composition check

```
cd video && npx hyperframes check
```

`0 error(s), 1 warning(s), 0 info(s)` — the one warning is `film_silent`: the project has no
`<audio>` and no `<video>`, because the film is delivered with no audio track for music to be
added to. Everything else — lint, runtime, layout, motion and contrast — is clean.

One deliberate exception inside that clean result: the terminal bodies and the window chrome carry
`data-layout-ignore`, so the 28 px reading floor is not applied to them. The longest line the film
shows verbatim is 117 characters and 22 px is the largest monospace size at which it fits the
frame; the alternative was cutting words out of recorded output. `video/STORYBOARD.md` says so in
the same words.

## The render

```
cd video
npx hyperframes render --output out/unstirred-demo.mp4 --fps 30 --quality delivery \
    --workers 3 --skill general-video
```

| | |
|---|---|
| Output | `video/out/unstirred-demo.mp4` |
| Duration | **147.000 s** — 2:27.0 |
| Frames | 4,410 at 30/1 fps |
| Resolution | 1920 x 1080 |
| Codec | h264, one stream — **no audio stream at all**, which is the empty track music goes onto |
| Size | **12,715,370 bytes** (12.1 MB), bit rate 691,992 |
| sha256 | `dff15ee3b708f9c8b5c76dc74b3b745ece6563bf8c8ecfc7a23327fa0bc207f0` |
| Wall time | 13 m 49.3 s — capture 10 m 52.8 s, encode 2 m 49.7 s, assemble 2.5 s |
| Capture mode | screenshot capture, software GPU, 3 workers (`BeginFrame did not run`) |

Read back with `ffprobe -v error -show_entries format=duration,size,bit_rate -show_entries
stream=codec_name,width,height,r_frame_rate,nb_frames,codec_type`.

The sha256 is this artifact's, not a reproducibility claim: the render is deterministic in what it
draws — no clock, no unseeded randomness, no network fetch in any composition — but the encoder and
the software GL stack are the machine's, so another machine may produce a different file of the
same frames.

```
cd video && npx hyperframes snapshot --at 5.5,20,31,53.5,81.5,95,103,110,117,133,143 --no-end -o out/stills
```

Eleven frames in `video/out/stills/`, one per scene, with two contact sheets beside them. They are

rather than carried in the repo.

## What is in the film

Nine beats over 2:27, planned in `video/STORYBOARD.md` before it was built, which names the
evidence file behind every scene. The honesty rule it is built under: every command and every
output line on screen is copied verbatim from the file its corner label names, two edits are made
and both are visible on screen (the owner's home path elided to `…/`, and a line over about
120 characters shortened with a `…`), and a compressed wait is marked `— cut —`.

**No invented duration appears anywhere.** The brief for the video asked that long waits read
`proving… (~60 s)`; no recorded run measures the wait, so the terminal keeps the recorded line
(`proving now; this takes seconds and reveals nothing to the gate but the package`) and the cut
carries no number. The film's one duration is act 8's "about 35 s of Halo2 verification", which
`README.md` records.

Scene 7a's four use cases are illustrative and are labelled `uses · illustrative, not measured` on
screen from the scene's first frame, with no mocked-up interface of any kind.

Nothing was run against either wallet to make this file.
