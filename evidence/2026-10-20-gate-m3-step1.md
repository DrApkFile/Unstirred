## What this run does not prove

- Nothing about the Zcash network. The gate under test pins a synthetic root and admits a proof
  about a synthetic wallet. A knock against a gate serving the real testnet wallet has not been
  run; the commands for it are in `HANDOFF.md` section 8.
- Not that two independent root sources agree: the service's tests inject the root authority, so
  the two-source rule itself is covered by A10, A10b, A27 and the recorded real run
  (`evidence/2026-10-20-roots-two-source.txt`).
- Not that a challenge expires: the gate's clock is stopped in these tests, and expiry is the
  store's own test (A07).
- Not that a running process keeps a secret off a channel. A39 reads the gate's rendered log
  lines and its response bodies; the leak scan reads tracked files.
- Not the Holders' Room page, which is M3 step 2 and not built.
