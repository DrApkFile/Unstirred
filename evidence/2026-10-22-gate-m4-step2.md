## What this run does not prove

- **Nothing about act 4 against the chain.** The act is a replay of two runs recorded earlier the
  same day (`evidence/2026-10-22-bob-forced-knock.meta.md` is their header); this gate run only
  shows that the act is a valid page state, that it renders in a document with no network call site
  and that its code words are `unstirred-core`'s own.
- **That the 413 is delivered under load.** The drain removes the reset that lost it, and A37
  passes, but a test on one machine cannot show a race is gone — only that it did not happen here.
  A client that keeps sending past the drain cap is still left to the close, deliberately.
- **That the page looks right.** That is a browser's job: act 4's own layout check, twenty-eight
  page variants with two of them looked at, is `evidence/2026-10-22-page-layout-check-act4.md`.

  and the layout-check evidence), because nothing here is committed and `git grep` skips untracked
  files. They were scanned by hand with the same patterns: no key material, no shielded address,
  and the only addresses anywhere in them are loopback.
- Nothing about a leak through a channel rather than a string in a running process, and nothing
