# LEAKS: Unstirred

Rubric: "Leaks are disqualifying, not deductions." Every channel below is either **defended with a
test** — the acceptance ID is named, and `briefing/PRD.md` §10 says what that ID asserts — or
**stated as a non-defence**, which means this repository does not defend it and says so rather
than implying otherwise. There is no third status: nothing here is planned, pending or
forthcoming. Where a row names a file in `evidence/`, that is a recorded run, indexed in
`CLAIMS.md`.

Read with [`SPEC.md`](../SPEC.md), which says what is proved and §10 of which lists the limits in
the same spirit.

## What this file cannot cover

- **A leak through a channel rather than a string.** `scripts/gate.sh` can scan a package, a
  database dump, a log line and a page for a value it knows. It cannot see timing, size or order
  as a channel in a running process. L13 is the one of those that is published on purpose.
- **Anything about a gate someone else runs.** These are properties of this code. An operator who
  adds a reverse proxy with its own access log has added a channel this file does not describe.
- **The soundness of the statement itself**, which is `SPEC.md` §3 and has had no external review.
